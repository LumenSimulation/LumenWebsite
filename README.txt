MORROW ARG WEBSITE — EASY EDITION

The important file is:

    config.js

Open config.js in VS Code and change the values near the top.

Example:

    modName: "Morrow",
    developerName: "Elias Venn",
    websiteName: "ModForge",

You can change those names and the entire website will update automatically.

You can also change:
- Minecraft version
- mod version
- release date
- AI designation
- mystery number
- tagline
- description
- fictional disclaimer

HOW TO OPEN IN VS CODE

1. Extract this ZIP.
2. Open VS Code.
3. Choose File > Open Folder.
4. Select the extracted "morrow_arg_easy_edit" folder.
5. Click config.js.
6. Change the values.
7. Save.
8. To view the website, open index.html in your browser.

IMPORTANT:
Do not edit the generated text in every HTML file just to change a name.
Use config.js for the main names and settings.

The website is designed as a fictional ARG prop.
